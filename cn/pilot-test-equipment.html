中试设备

(NAOP 系列)

下载产品目录
Neotec UV 中试设备 是一套紧凑型移动式系统，专为 UV-AOP 处理工艺的现场测试及预验证而设计。

该设备可模拟实际运行条件，以确定最佳 UV 和氧化剂运行参数，并评估难降解有机污染物的去除效果。

测试结果可为全规模处理系统的设计优化提供重要数据支持。

主要特点

Neotec UV 中试设备 用于评估 UV 处理性能，为全规模系统的设计与优化提供支持。
‍
• 紧凑型撬装设计，可使用 1 吨卡车运输
• 同时配备低压和中压 UV 反应腔
• 通过内部水循环进行批次测试
• 流量及运行条件可调
• 饮用水应用最大处理流量：100 m³/天
• 可进行污染物加标试验，以评估污染物去除效果

应用领域

• 饮用水（Geosmin、2-MIB、NDMA、1,4-二氧六环等）
• 污水及工业废水（TOC 和 COD 降解、有机污染物去除）

CBD 测试

在评估 UV-AOP 处理工艺的适用性时（例如低压/中压 UV 系统的选择），通常首先进行 CBD（准直光束装置）测试，随后通过中试设备验证处理效果。
‍
该测试利用受控 UV 光束，在不同条件下评估工业废水中污染物的去除效果。

中试设备组成

1. 流量计
实时测量水流量
2. 中压 UV 反应腔
配备 1.5–3 kW 中压 UV 灯
配备 UV 强度传感器及温度传感器
3. 供水泵
通过控制系统供水并调节水流量
4. 控制系统
监测并控制 UV 灯输出功率、UV 强度及水流量
5. 低压 UV 反应腔
配备 550 W 低压 UV 灯
配备 UV 强度传感器及温度传感器
6. 氧化剂供给系统
从储存罐自动供给氧化剂
可在加标试验中供给污染物
